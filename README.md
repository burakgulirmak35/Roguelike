## 📖 About

**CyberDeadZone** is a roguelike action game set in a dark cyberpunk world. Fight through procedurally challenging zones, survive waves of enemies, and push deeper into the dead zone — if you dare.

---

## 🛠️ Built With

- **Engine:** Unity
- **Language:** C#
- **Shaders:** ShaderLab / HLSL (custom visual effects)
- **Platform:** Android (Mobile)
- **IDE:** JetBrains Rider / Visual Studio

## 🚀 Getting Started

### Prerequisites

- [Unity](https://unity.com/download) (check `ProjectSettings/ProjectVersion.txt` for the required version)
- Android Build Support module installed via Unity Hub

### Installation

```bash
git clone https://github.com/burakgulirmak35/CyberDeadZone.git
```

1. Open **Unity Hub**
2. Click **Add project from disk** and select the cloned folder
3. Open the project and let Unity import all assets
4. Switch the build target to **Android** via `File > Build Settings`
5. Hit **Play** to run in the editor
